## 更新ルール

- どちらかの環境を変えたら（pull、リビルド、再起動、`.env` の変更、DB の一括操作、バックアップの取得など）、**同じ日のうちにこのファイルを更新してコミットする**
- 更新するのは該当する環境の節と、末尾の「更新履歴」の 1 行
- 値は推測で書かない。確認していない項目は「未確認」と書き、確認したら埋める。確認方法は「確認コマンド」の節にある
- API キーなどの秘密情報は書かない（`.env` はキー名と秘密でない値だけ）

## 確認コマンド

どちらの環境でも、リポジトリのディレクトリで実行する。Windows の Git Bash では、パスが書き換えられないよう先に `export MSYS_NO_PATHCONV=1` を実行する。

```bash
# コードとコンテナ
git log -1 --format='%h %ci %s'
git status --short
docker compose version
docker compose ps
docker image inspect $(docker compose images -q backend) --format '{{.Created}}'

# コンテナ内のコードが main と同じか（2 つのハッシュが一致すれば同じ）
docker compose exec -T backend sha256sum /app/app.py
sha256sum backend/app.py

# .env のキー名だけ（値は出さない）
sed -E 's/=.*//' .env | grep -v '^#' | grep -v '^$'

# DB の状態（読み取り専用で開く）
docker compose exec -T backend python - <<'EOF'
import sqlite3
c = sqlite3.connect('file:/app/data/worklog.db?mode=ro', uri=True)
q = lambda s: c.execute(s).fetchall()
print("journal_mode", q("PRAGMA journal_mode"))
print("indexes", [r[0] for r in q("select name from sqlite_master where type='index' and name not like 'sqlite_%'")])
print("worklog total/active/deleted", q("select count(*), sum(deleted_at is null), sum(deleted_at is not null) from worklog"))
print("FIX-MAINT deleted", q("select count(*) from worklog where parent_key='FIX-MAINT' and deleted_at is not null"))
print("bad added_at", q("select count(*) from worklog where added_at not glob '[0-9][0-9][0-9][0-9]-[0-9][0-9]-[0-9][0-9]T[0-9][0-9]:[0-9][0-9]:[0-9][0-9]'"))
EOF
```
