## Q1. 「1人月」の換算基準時間 ★★★

Backlogの予定工数は「時間（h）」で保持されています。これを「人月」に換算する基準について：

- **A 案（採用）: デフォルト 160 時間/人月 とし、144h / 152h / 160h / 168h / 176h / 184h を切り替え可能にする**
- B 案: 160 時間/人月 固定
- C 案: 月ごとの実働営業日数 × 8 時間 で月ごとに自動変動させる

👉 **回答**: 8時間/日になるので、160時間をデフォルト、144h/152h/160h/168h/176h/184hを切り替え可能にする。

---

## Q2. 月別工数の按分（配分）ロジック ★★★

課題が複数月に跨がる場合の工数配分方法について：

- A 案: 暦日数（カレンダー日数）による日割り按分
- **B 案（採用）: 営業日数（土日を除く平日日数）による日割り按分**
  - 月末・月初や大型連休の営業日数を考慮したより精緻な配分。
- C 案: 期限日（due date）の属する月に全工数を計上（按分なし）

👉 **回答**: B案にします。（土日を除く営業日数ベースでの按分計算）

---

## Q3. 集計対象とする工数の種類 ★★★

マトリクス表で集計・表示する工数は何にしますか？

- **A 案（採用）: 予定工数（`plannedH`）をベースとし、完了フラグ等で絞り込み可能にする**
  - 当初のアサイン計画・要員負荷を正確に確認できます。
  - フィルタ「✅ 処理済み・完了を隠す」をONにすることで、現在残っている進行中タスクの予定工数に絞り込めます。
- B 案: 残工数（`remainingH`）をベースにする
- C 案: 表示切替で「予定工数 / 残工数」を選択可能にする

👉 **回答**: A案にする

---

## Q4. 開始日・期限日が未設定（または片方のみ）の課題の扱い ★★

Backlog上で開始日や期限日が設定されていない課題がある場合の扱いです。

- **A 案（採用）: 「日付未設定」列をマトリクス右端に常設し、期間不明の工数も漏れなく把握できるようにする**
  - 片方のみ設定の場合: 期限日のみあれば期限日の月、開始日のみあれば開始日の月に計上。
  - 両方未設定の場合: 「日付未設定」列に計上。
- B 案: 日付が不完全な課題は月別集計から除外し、画面上部に警告表示する

👉 **回答**: A案にする

## Q5. 表示単位（人月 / 時間）の切り替え ★★

- **A 案（採用）: 「人月（例: 0.85）」と「時間（例: 136.0h）」をワンクリックで切り替え可能にする**
- B 案: 「人月」のみ表示

👉 **回答**: A案でお願いします

## Q7. セルクリック時のドリルダウン（内訳確認・編集） ★★

マトリクスの数値（例: 山田さんの2026/05 = 1.2人月）をクリックしたときの動作です。

- **A 案（採用）: クリックするとその月に配分された子課題の内訳（案件名・課題名・配分工数）がポップアップ表示され、課題名クリックで詳細編集モーダル（担当者・工数・日程変更）が開く**
- B 案: 内訳表示のみ
- C 案: セルクリック機能なし

👉 **回答**: A案で良い

## Q8. 過負荷・空きの強調表示（ヒートマップ色分け） ★

セルの人月に応じた色分けについて：

- **推奨仕様（採用）**:
  - `> 1.0 人月` : 🔴 赤系ハイライト（過負荷・残業水準）
  - `0.8 〜 1.0 人月` : 🟢 緑系（適正稼働）
  - `0.1 〜 0.7 人月` : 🟡 黄系（余力あり）
  - `0.0 人月` : グレー（割当なし・完全な空き）

👉 **回答**: 推奨で良い

👉 **回答**: A案で良い。ガントチャートの担当者のようにフィルタリングできるようにしたい。（複数選択可）
